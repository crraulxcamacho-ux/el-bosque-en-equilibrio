ABRIR EN VISUAL STUDIO CODE
1. Descomprime el ZIP.
2. En Visual Studio Code, selecciona Archivo > Abrir carpeta.
3. Abre esta carpeta.
4. Abre index.html.
5. Visualiza index.html en el navegador o utiliza Live Server.
